Student Grade Management System

About the Project

This is a Java console-based application developed as part of my CodeOrbit Tech Java Programming Internship.

Features

- Accepts student names and marks.
- Stores information using arrays.
- Calculates average marks.
- Finds the highest marks.
- Finds the lowest marks.
- Displays a formatted student report.

Technologies Used

- Java
- Scanner Class
- Arrays
- For Loop
- Conditional Statements
- Eclipse IDE

How to Run

1. Install Java JDK.
2. Open the project in Eclipse IDE.
3. Open "StudentGradeManagement.java".
4. Run the program.
5. Enter the number of students, names, and marks.
